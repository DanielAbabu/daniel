# Daniel Ababu Tegegen — Portfolio

A high-performance personal portfolio built with Vite, React, and TanStack Router. Showcasing selected projects, work experience, and ways to get in touch.

**Live site:** [daniel-ababu.vercel.app](https://daniel-ababu.vercel.app) *(update with your actual URL)*

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | [Vite](https://vitejs.dev/) + [React 19](https://react.dev/) |
| Routing | [TanStack Router](https://tanstack.com/router) (file-based) |
| Styling | [Tailwind CSS v4](https://tailwindcss.com/) |
| Animation | [Framer Motion](https://www.framer.com/motion/) |
| Typography | Fraunces, Inter, JetBrains Mono (Google Fonts) |
| Deployment | [Vercel](https://vercel.com/) |

## Local Development

### Prerequisites

- Node.js ≥ 18
- npm (or bun)

### Setup

```bash
# Clone the repo
git clone https://github.com/DanielAbabu/daniel-ababu-portfolio.git
cd daniel-ababu-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

The dev server will be available at `http://localhost:5173`.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
| `npm run format` | Format with Prettier |

## Deployment

The site deploys automatically to Vercel on every push to `main`.

### Manual Deploy

1. Push changes to `main`
2. Vercel auto-detects the Vite framework
3. Build command: `npm run build`
4. Output directory: `dist`

The `vercel.json` contains a catch-all rewrite rule so client-side routing works correctly on page refresh:

```json
{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
```

### Adding a Resume

Place your resume PDF at `public/resume.pdf` — the header "Resume" button links to `/resume.pdf` automatically.

## Customization

All personal content is centralized in two files:

- **`src/lib/site-data.ts`** — Name, bio, skills, experience, social links, availability status
- **`src/lib/projects.ts`** — Project case studies with tech stack, outcomes, and Mermaid architecture diagrams
